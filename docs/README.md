# Internal Engineering Docs

This folder (`/docs`) is for **internal engineering documentation** only. 

These documents are NOT published to the public `docs.makinari.com` site (which lives in `/src/content`).

## Guidelines
- Do not put customer-facing documentation here.
- Use this folder for postmortems, internal setup guides (like SendGrid or WhatsApp approvals), and architectural decisions.
- Note that other frontends (market-fit, commercial-site, partners-portal) might contain duplicate `docs/` folders. Prefer to centralize shared infrastructure knowledge here or in a dedicated internal wiki, rather than duplicating it across repos.
