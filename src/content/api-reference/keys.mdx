# API Keys

Generate, list, and revoke API keys for your Site.

<div className="endpoint-block">
  <MethodChip method="GET" />
  <code>/api/keys</code>
</div>

## Request Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `site_id` | `string` | Yes | The UUID of your Site. |

## Example Request

```bash
curl -X GET "https://backend.makinari.com/api/keys?site_id=YOUR_SITE_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Interactive Tester

<ApiTester 
  method="GET" 
  endpoint="/api/keys" 
  defaultParams={{ site_id: "YOUR_SITE_ID" }}
/>

## Response

Returns an array of active API keys (metadata only, the secret key is never returned after creation).
