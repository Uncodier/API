# Changelog

All notable changes to the Makinari platform, API, and documentation will be documented in this file.

## [2026-08-31]
### Added
- **Makinari Docs:** Complete restructuring of the documentation. 
  - Introduced unified paths for Inbound, Outbound, AI Goals, API, and MCP onboarding.
  - Added new Concept and Guides sections.
  - Unified API Reference with interactive `ApiTester`.
  - Grouped all MCP tools under a single Tools Catalog.

### Changed
- Clarified the Dual Auth Model (CORS vs API Key).
- Updated documentation base URL to `docs.makinari.com` and backend URL to `backend.makinari.com`.

### Removed
- Legacy `/first-steps`, `/rest-api`, `/agents`, `/channels`, `/workflows`, and `/content-api` structures (redirected to their respective new locations).
