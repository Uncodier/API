# Catalog Commerce

Create, search, and manage catalog items and product modifiers. Default `resource="item"`: use `action="create"` to add a product/service/digital_asset (requires `name`; set `target_sale_price` and `is_purchasable` for sellable items). Use `list`/`get`/`update` for items. An item with `is_reservation = true` needs a schedule via `reservation_schedules` before it can be sold.

**Modifiers** (extras like toppings or size options):

1. `resource="modifier_group"` — create a reusable selection group (`min_select` / `max_select`).
2. `resource="modifier_group_item"` — add catalog items as options inside the group.
3. `resource="item_modifier_group"` — attach the group to a host product.
4. `resource="item"` + `action="get"` + `include_modifiers=true` — read a product with its groups and options.

## Input Schema

| Parameter | Type | Description |
| :--- | :--- | :--- |
| action | string | create, list, get, update, delete (`delete` for modifier resources only) |
| resource | string | item (default), modifier_group, modifier_group_item, item_modifier_group |
| id | string | Target UUID (required for get, update, delete) |
| site_id | string | Seller site UUID |
| name | string | Name (required for create on item or modifier_group) |
| description | string | Description |
| sku | string | SKU code (unique per site) |
| image_url | string | Public HTTP URL for the product image |
| cost | number | Cost / COGS |
| lowest_sale_price | number | Minimum allowed sale price |
| target_sale_price | number | Default sale price used by checkout/quotes |
| kind | string | Kind: product, service, digital_asset |
| digital_subtype | string | Subtype: ticket, course, file, pass, license |
| is_marketplace_listed | boolean | True if visible in the marketplace |
| is_reservation | boolean | True if the item requires a schedule/slot to be booked before checkout |
| is_purchasable | boolean | True if item can be bought |
| is_recurring | boolean | True if item is a subscription plan |
| is_pos_available | boolean | True if item is available in Point of Sale |
| status | string | Status: active, archived |
| availability_status | string | Availability: available, unavailable, sold_out |
| currency | string | Currency code (e.g. USD, MXN) |
| category_id | string | Category UUID |
| parent_id | string | Parent catalog item UUID (for variants) |
| search | string | Search term for name/description |
| sort_order | number | Sort order for display |
| modifier_group_id | string | Modifier group UUID |
| catalog_item_id | string | Option catalog item (group item) or host product (attachment) |
| min_select | number | Minimum options the buyer must pick |
| max_select | number | Maximum options (null = unlimited) |
| include_modifiers | boolean | On item get, include attached groups + options |
| limit | number | Limit results for list |
| offset | number | Offset results for list |

## Example — Create product

```json
{
  "action": "create",
  "name": "Cold Brew",
  "kind": "product",
  "target_sale_price": 45,
  "currency": "MXN",
  "is_purchasable": true,
  "is_pos_available": true,
  "image_url": "https://example.com/cold-brew.jpg"
}
```

## Example — Modifier group + options + attach

```json
{
  "action": "create",
  "resource": "modifier_group",
  "name": "Milk options",
  "min_select": 0,
  "max_select": 1
}
```

```json
{
  "action": "create",
  "resource": "modifier_group_item",
  "modifier_group_id": "GROUP_ID",
  "catalog_item_id": "OAT_MILK_CATALOG_ITEM_ID",
  "sort_order": 0
}
```

```json
{
  "action": "create",
  "resource": "item_modifier_group",
  "catalog_item_id": "COLD_BREW_ID",
  "modifier_group_id": "GROUP_ID"
}
```

## Example — Read product with modifiers

```json
{
  "action": "get",
  "resource": "item",
  "id": "COLD_BREW_ID",
  "include_modifiers": true
}
```
